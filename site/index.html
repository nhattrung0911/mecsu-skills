Bắt đầu

Copy đoạn dưới, dán vào AI của bạn.

Cài plugin skill từ repo nhattrung0911/mecsu-skills, xác nhận skill đã nhận diện, và cho biết cần cài thêm gì.

Skill 1

/mecsu-category — soát danh mục đã gán.

Kiểm tra danh mục đã gán trong file của tôi, dừng ở lô hiệu chuẩn cho tôi đọc trước.

Skill 2

/mecsu-filter — soát và bổ sung thông số.

Soát thông số trong file của tôi, mỗi đề xuất phải kèm giá trị cụ thể và căn cứ.

Điểm kiểm soát

Thoát khác 0 nghĩa là không giao.

Skill tự mở lại file nó vừa dựng và so với file gốc: số dòng, dòng không đụng tới, id danh mục. Lệch một chỗ là dừng, không phải "chạy lại kèm cờ khác cho qua". Ô chưa đủ bằng chứng nằm lại ở khu review, không đẩy sang thư mục đã giao.

Hỏi đáp

Cần biết trước khi dùng.

Chưa có API key thì chạy được không?

Được, phần đầu vẫn chạy vì nó không gọi model. Script sẽ tự dừng và in đường dẫn file .env cần điền khi tới bước cần key.

Vì sao nó dừng giữa chừng rồi bắt đọc?

Đó là lô hiệu chuẩn 50 câu. Đọc lô này là cách rẻ nhất để phát hiện sai sót trước khi trả tiền cho cả file.

Ô đánh dấu REVIEW là ô sai à?

Không. REVIEW nghĩa là dữ liệu trong file không đồng ý với giá trị đề xuất. Đối chiếu bảng tra tiêu chuẩn hoặc tra web rồi mới quyết — chính file nguồn cũng có thể sai.

Agent có được tự báo hoàn tất không?

Không. Còn cặp tranh chấp chưa ai quyết thì bước giao file bị chặn, và sự từ chối đó là tính năng.

**Công thức chiều dài ren** (kiểm chứng khớp mọi dòng trên):

- L ≤ 125: `b = 2d + 6`
- 125 < L ≤ 200: `b = 2d + 12`
- L > 200: `b = 2d + 25`

Suy ra M22→50/56/69, M30→66/72/85 (không có trong bảng nguồn nhưng theo công thức).
DIN 933 dùng chung `s` và `k` với DIN 931, khác ở chỗ ren suốt.

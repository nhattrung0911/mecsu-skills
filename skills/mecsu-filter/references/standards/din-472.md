# DIN 472 — bảng chuẩn cho dải lỗ 44-56 (đã xác minh 2 nguồn)

Dùng để ĐỐI CHIẾU dữ liệu trong file, không dùng để sinh tên. Số lấy từ:

- [Standard Internal Circlips to DIN 472 Metric (anda.be)](https://www.anda.be/wp-content/uploads/2022/05/Circlips-bus-DIN472-1.pdf) — bảng đầy đủ, cột `G` = đường kính rãnh, `W` = bề rộng rãnh, `D` = đường kính ngoài vòng găng
- [boltsfastener.com DIN 472](https://www.boltsfastener.com/standards/retaining-rings-standards/din-472.html) — đối chiếu cột D

| Lỗ (d1) | Ø ngoài D | Dày t | Ø rãnh G | Rộng rãnh W |
|---|---|---|---|---|
| 44 | 47.5 | 1.75 | 46.5 | 1.85 |
| 45 | 48.5 | 1.75 | 47.5 | 1.85 |
| 46 | 49.5 | 1.75 | 48.5 | 1.85 |
| 47 | 50.5 | 1.75 | 49.5 | 1.85 |
| 48 | 51.5 | 1.75 | 50.5 | 1.85 |
| **49** | **không có trong chuẩn** | | | |
| 50 | 54.2 | 2.00 | 53.0 | 2.15 |
| 51 | 55.2 | 2.00 | 54.0 | 2.15 |
| 52 | 56.2 | 2.00 | 55.0 | 2.15 |
| 53 | 57.2 | 2.00 | 56.0 | 2.15 |

| 55 | 59.2 | 2.00 | 58.0 | 2.15 |
| 56 | 60.2 | 2.00 | 59.0 | 2.15 |

Quy luật trong dải:

- dày 1.75 (lỗ 44-48): **Ø rãnh = lỗ + 2.5**, **Ø ngoài = lỗ + 3.5**
- dày 2.00 (lỗ 50-56): **Ø rãnh = lỗ + 3.0**, **Ø ngoài = lỗ + 4.2**

Cả hai nguồn đều **không có lỗ 49 và 51 là cỡ ưu tiên**; bảng anda có 51, bảng
boltsfastener không. Lỗ 49 vắng ở cả hai.
